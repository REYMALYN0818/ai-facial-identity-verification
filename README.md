AI-Based Facial Identity Verification and Anti-Impersonation System

Project Description

This project is a web-based system designed to support facial identity registration and verification request management. It allows users to register their facial profiles, submit verification requests, and view their verification history. Administrators can review requests and update their status.

Features

- User Registration and Login
- Facial Profile Registration
- User Consent Collection
- Facial Verification Request Submission
- Verification History
- Admin Dashboard
- Approval and Rejection of Requests

Technologies Used

- PHP
- Laravel Framework
- MySQL
- HTML
- CSS
- Bootstrap 5
- JavaScript
